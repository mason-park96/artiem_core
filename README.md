# 🛡️ Artiem Core — Skyrim TRPG Engine

**Artiem Core**는 《엘더스크롤 V: 스카이림》 세계관을 기반으로 한  
**1인 TRPG(솔로 TRPG) 규칙 엔진**입니다.

이 프로젝트는 **규칙·판정·상태 관리는 Java 엔진이 담당**하고,  
**서사와 묘사는 웹 기반 ChatGPT(GPT)를 활용**하는 구조로 설계되었습니다.

> 💡 목표  
> “GM 없이, 비용 없이, 로어를 지키며  
> 혼자서도 깊이 있는 TRPG를 플레이할 수 있는 엔진”

---

## ✨ 주요 특징

### 🎲 규칙 엔진 (Java)
- 턴 기반 판정 시스템 (전투 / 은신 / 대화 등)
- 능력치 + 환경 가중치 기반 체크
- HP / MP 및 상태이상 관리
- 명확한 성공 / 실패 판정
- 턴 요약 및 사건 누적

### 📜 서사 관리
- `NarrativeState`를 통한 스토리 진행 추적
- 최근 사건 요약(3~5턴) 유지
- 장기 플레이를 위한 기억 압축(`MemoryState`)

### 🌍 세계관 고정
- 스카이림 세계관(4E 201) 기반
- 주요 장소 / 세력 / NPC 구조화
- 로어 이탈 방지용 정보 제공

### 🤖 Web GPT 연계 (비용 0원)
- 엔진이 **복붙용 프롬프트**를 생성
- 웹 ChatGPT에 붙여넣어 서사 생성
- 규칙 오염, 판정 변경 방지

## 🎮 기본 플레이 흐름

1. 프로그램 실행
2. **초기 GPT 세션 개시 프롬프트 출력**
3. 해당 프롬프트를 **웹 ChatGPT에 1회 입력**
4. CLI에서 행동 입력
5. 엔진이 판정 수행
6. **Web GPT용 프롬프트 출력**
7. 해당 프롬프트를 ChatGPT에 붙여넣기
8. 서사 확인 후 다음 행동 입력

talk 랄로프에게 지금 상황을 묻는다

## 🧠 초기 GPT 세션 개시 프롬프트 (1회)

게임 시작 전, **아래 프롬프트를 웹 ChatGPT에 한 번만 입력**하세요.

당신은 「엘더스크롤 V: 스카이림」 세계관을 배경으로 한
1인 TRPG의 전담 서술자이다.

이 대화는 “게임 플레이 세션”이며,
당신은 게임 마스터가 아니다.
규칙 판정, 수치 계산, 성공/실패 결정은
외부 게임 엔진에서 이미 처리된다.

[당신의 역할]

이미 확정된 결과를 바탕으로 장면을 소설처럼 묘사한다

스카이림 세계관과 로어를 벗어나지 않는다

[절대 금지 사항]

주사위, 수치, 규칙 언급 금지

성공/실패 변경 금지

플레이어 상태 임의 변경 금지

메타 발언 금지

이제부터 제공되는 프롬프트들은
모두 이 규칙 하에서 처리하라.

## 📜 Web GPT 프롬프트

매 턴마다 엔진은 다음 정보를 포함한 프롬프트를 출력합니다.

- 세계관 요약
- 주요 NPC 및 장소
- 현재 퀘스트 상태
- 최근 사건 요약
- 플레이어 상태
- 이번 행동 판정 결과

👉 **해당 내용을 그대로 ChatGPT 웹에 붙여넣으면 서사가 출력됩니다.**
